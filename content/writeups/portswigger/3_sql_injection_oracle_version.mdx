- Objetivo:  Obtener la versión del sistema de gestión de base de datos Oracle utilizando una inyección SQL basada en `UNION`.

## **Análisis inicial**

Este laboratorio presenta una vulnerabilidad de inyección SQL en la URL, dentro del parámetro `category`. El backend utiliza Oracle como sistema gestor de base de datos. El objetivo es identificar la versión exacta del motor mediante una consulta manipulada.

## Consulta original:

```sql
SELECT * FROM articles WHERE category = ''
```

La consulta filtra los artículos según la categoría proporcionada en la URL. Esta entrada es vulnerable y puede ser manipulada para ejecutar consultas arbitrarias mediante la cláusula `UNION`.

## 🔎 Observación sobre UNION

La inyección SQL basada en `UNION` permite combinar resultados de múltiples sentencias `SELECT` en una sola salida. Es útil cuando el atacante quiere recuperar datos adicionales de otras tablas, como versiones, usuarios, contraseñas, etc.

## Solución

- **Vulnerabilidad:**
    
    El parámetro category no está debidamente validado ni parametrizado, lo que permite que un atacante inyecte instrucciones SQL adicionales.
    Al explotar esta vulnerabilidad mediante la cláusula UNION SELECT, se pueden consultar tablas internas del sistema, como v$version, usada en Oracle para obtener información del motor de base de datos.
    
- **Paso 1: Determinar el número de columnas**
    
    Antes de usar `UNION`, necesitamos saber cuántas columnas devuelve la consulta original. Para eso, se usa la técnica `ORDER BY`.
    
    **Payloads utilizados:**
    
    ```sql
    ' ORDER BY 1--
    ' ORDER BY 2--
    ' ORDER BY 3-- <-Error
    ```
    
    - Se incrementa el número hasta provocar un error.
    - En este caso, `ORDER BY 3` falla, lo que indica que hay **2 columnas**.
    
- **Paso 2: Validar la inyección `UNION`**
    
    Una vez sabemos que hay 2 columnas, probamos una inyección básica para confirmar que `UNION SELECT` funciona correctamente en Oracle.
    
    **Payload de prueba:**
    
    ```sql
    ' UNION SELECT 'ABC','NULL' FROM dual--
    ```
    
    - En Oracle, cuando no se hace referencia a una tabla específica, se utiliza la tabla especial `DUAL`.
    - Este payload prueba si podemos controlar la salida de la consulta.

- **Paso 3: Obtener la versión de Oracle**
    
    Finalmente, se usa una tabla específica de Oracle llamada `v$version`, que almacena información del sistema y del motor de base de datos.
    **Payload final:**
    
    ```sql
    'UNION SELECT banner, 'NULL' FROM v$version--
    ```
    
    - `banner` es una columna que contiene información de la versión de Oracle.
    - `NULL` se usa para completar la segunda columna y mantener la cantidad igual a la consulta original.

## ✅ Resultado

Con la inyección anterior, se muestra la versión de Oracle:

```
CORE 11.2.0.2.0 Production
```
