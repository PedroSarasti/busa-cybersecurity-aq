- Objetivo:  Iniciar sesión como el usuario `administrator` mediante inyección SQL en el formulario de login.

## **Análisis inicial**

La aplicación presenta un formulario de inicio de sesión con campos `username` y `password`. Al enviar las credenciales, se ejecuta una consulta SQL en el servidor que verifica si existe un usuario con ese nombre y contraseña.

## Consulta original:

```sql
SELECT * FROM users WHERE username = 'administrator' AND password = ''
```

## Solución

- **Vulnerabilidad**:
    
    Si el parámetro `username` es vulnerable a inyección SQL, se puede manipular para:
    
    - Finalizar prematuramente la cadena.
    - Omitir la condición de contraseña (`AND password = ''`).
    - Comentar el resto de la consulta con `-`.

- **Payload inyectado:**
    
    Opción 1 (suficiente en este laboratorio):
    
    ```sql
    administrator'--
    ```
    
    Consulta resultante:
    
    ```sql
    SELECT * FROM users WHERE username = 'administrator''-- AND password = ''
    //------------------------------------------------------------------------------//
    SELECT * FROM users WHERE username = 'administrator'' OR 1=1-- AND password = ''
    ```
    
    El comentario `--` ignora el resto de la consulta (`AND password = ''`), permitiendo el acceso sin necesidad de conocer la contraseña.
    

## ✅ Resultado

La inyección permite iniciar sesión directamente como el usuario `administrator`, resolviendo el laboratorio con éxito.
