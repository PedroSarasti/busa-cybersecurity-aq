- Objetivo:  Explotar una vulnerabilidad de tipo Cross-Site Scripting (XSS) reflejado en la funcionalidad de búsqueda de la aplicación, logrando ejecutar código JavaScript (función `alert`) en el navegador.

## **Análisis inicial**

El parámetro de búsqueda no está correctamente validado ni codificado en la respuesta HTML.

Esto permite inyectar directamente código HTML/JavaScript que será interpretado por el navegador.

## Solución

- Se inyecta un payload XSS básico en el parámetro de búsqueda para provocar la ejecución de código JavaScript:

```jsx
<script>alert(1)</script>
```

Payload completo en la URL:

```
GET /?search=<script>alert(1)</script>
```

El payload se refleja y es interpretado por el navegador, ejecutando la función `alert`.
